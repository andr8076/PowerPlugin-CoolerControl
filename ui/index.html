Temperature protection

These sensors show power usage, not hardware temperature. For temperature protection, combine your power curve with an actual temperature curve using a Maximum Mix Profile. Missing readings report 100°C.

Fan curves

1. Set the maximum wattage for each source above.

2. Create a Graph Profile with a Power to Temperature sensor.

3. Apply the curve to your fans or combine it with another profile.

Example: 500 W maximum, 250 W measured → 50°C virtual.
